\section{Publications \& Tech Projects}

\myhighlightblue{Tech-Report} \textbf{IQuest-Q1: Advancing Foundation Capabilities for Agentic CLI Systems}

\faGithub~\href{https://github.com/IQuestLab/IQuest-Q1}{IQuestLab/IQuest-Q1}
\hspace{2em}\hficon~\href{https://huggingface.co/IQuestLab/IQuest-Q1}{IQuest-Q1 Model Page}
\hspace{2em}\faGlobe~\href{https://iquestlab.github.io/}{Project Page}

Contributed to \textbf{IQuest-Q1}, a 320B-parameter Mixture-of-Experts model with 15B active parameters per token, designed for agentic coding, reasoning, and multi-step tool use in CLI environments. The model is trained on synthetic medium- and long-horizon tasks using multi-harness reinforcement learning and multi-teacher on-policy distillation (MOPD).
\newline

\textbf{RSI-Master: Structuring Experiments to Guide Autonomous Model Improvement}

\myhighlightred{Incoming submission for ICLR 2027 (Co-first author)}

\arxivicon~\href{https://arxiv.org/abs/2609.35561}{arXiv: 2609.35561}
\hspace{2em}\faGithub~\href{https://github.com/DorothyDUUU/RSI-Master}{DorothyDUUU/RSI-Master}

Pioneered \textbf{RSI-Master}, which combines an Experiment OS with Reviewer-Guided Research Orchestration to prevent reward hacking and strategy lock-in in autonomous model development. On PostTrainBench with Qwen3-4B-Base, it achieved 54.49 versus 46.53 for the strongest agent baseline with a 0.0\% hacking rate; at 35B, it surpassed the human-developed Instruct model on LiveCodeBench-v6 (41.21 vs. 37.36) and SciCode.
\newline

\textbf{DataMaster: Data-Centric Autonomous AI Research}

\myhighlightred{Incoming submission for ICLR 2027 (Co-first author)}

\arxivicon~\href{https://arxiv.org/abs/2605.10906}{arXiv: 2605.10906}
\hspace{2em}\faGithub~\href{https://github.com/sjtu-sai-agents/DataMaster}{sjtu-sai-agents/DataMaster}

Proposed and developed DataMaster automating external data discovery, selection, and cleaning to enhance ML and post training tasks. Designed a system combining tree-structured search, shared data pool to navigate open-ended search spaces and carry global memory across branches. Successfully boosted the MLE-Bench Lite medal rate by 32.27\% and surpassed the instruct model on PostTrainBench (GPQA: 31.02\% vs. 30.35\%).
\newline

\myhighlightred{ICML-2026} \textbf{MCP-Persona: Benchmarking LLM Agents on Real-World Personal Applications via Environment Simulation}

\textbf{Co-first author}
\hspace{2em}\arxivicon~\href{https://arxiv.org/abs/2606.02470}{arXiv: 2606.02470}
\hspace{2em}\faGithub~\href{https://github.com/wwh0411/MCP-Persona}{wwh0411/MCP-Persona}

Pioneered \textbf{MCP-Persona}, the first benchmark for evaluating LLM agents on \textbf{personalized} Model Context Protocol (MCP) tools. MCP-Persona captures real-world challenges of tools interacting with individual accounts and local databases across diverse platform including Reddit, Xiaohongshu, Lark, and Slack. Extensive evaluations of state-of-the-art agents reveal substantial deficiencies in personalized tool utilization.
\newline 

\myhighlightred{ICLR-2026} \textbf{InfoMosaic-Bench: Evaluating Multi-Source Information Seeking in Tool-Augmented Agents}

\textbf{3rd Author}
\hspace{2em}\arxivicon~\href{https://arxiv.org/abs/2510.02271}{arXiv: 2510.02271}
\hspace{2em}\faGithub~\href{https://github.com/DorothyDUUU/Info-Mosaic}{DorothyDUUU/Info-Mosaic}

Pioneered \textbf{InfoMosaic-Bench}, the first benchmark dedicated to multi-source information seeking in LLM agents, demonstrating the critical need to integrate general-purpose web search with thousands of domain-specific tools via \textbf{MCP} (Model Context Protocol). Experiments revealed that web information alone is insufficient (GPT-5 Acc: 38.2\%) for information seeking due to incorrect tool usage/selection.
\newline 


\myhighlightblue{Tech-Report} \textbf{AppCopilot: Toward General, Accurate, Long‑Horizon, and Efficient Mobile Agent}
